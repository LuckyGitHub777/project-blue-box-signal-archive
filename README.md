# Signal Archive — An Imagined Transmission

An original fictional, offline-first visual studio. Explore three invented signals, collect them in tab memory, and reset the experience. No accounts, telemetry, third-party scripts, server, external fonts, live radio, scientific detections, security exploits or actual transmissions.

Open `index.html` directly in a browser. Run `npm test` with Node.js 20+ for the offline interaction checks. No install dependencies.
