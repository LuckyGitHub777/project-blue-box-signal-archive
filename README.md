# Signal Archive — An Imagined Transmission

**A fictional signal receiver you can explore offline.** Three invented transmissions, each with its own story and visual pattern. Nothing here is a live radio signal, scientific detection, historical record, or actual transmission.

## Enter the archive

1. Select **Code → Download ZIP** on GitHub, extract the folder, and open `index.html` in your browser. The GitHub file preview shows source code, not the interactive page.
2. Choose **Pulse**, **Echo**, or **Horizon** to change the receiver's waveform and story.
3. Choose **Keep this signal** to collect a favorite, or **Remove from collection** to reverse the choice. **Clear collection** starts over.

Selections live only in the current browser tab's memory. There is no account, telemetry, server, third-party script, external font, or network request. The experience includes keyboard controls and reduced-motion support.

## Explore the source

- [`index.html`](index.html) — the visual receiver and story.
- [`styles.css`](styles.css) — layout and responsive presentation.
- [`app.js`](app.js) — the three fictional signals and local collection behavior.
- [`tests/studio.test.mjs`](tests/studio.test.mjs) — offline behavior and safety checks.

With Node.js 20 or later, run `npm test` to execute the dependency-free tests.
